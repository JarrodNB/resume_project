# Accessibility Loop

Read and follow the [shared protocol](../super-loop/references/iteration-protocol.md) for count selection, isolation, verification, fresh review, publication, and stopping.

Choose a reproducible barrier in an existing complete user flow: keyboard access, focus, names, semantics, announcements, contrast, or motion. Read applicable frontend instructions and the available Impeccable skill. Record the affected task and expected accessible interaction. Verify keyboard and focus behavior, accessible roles and names, and relevant automated checks; use screen-reader testing when available. Report unavailable manual checks. Do not infer comprehensive compliance from automation or expand into unrelated redesign.

When coordinated by super-loop, use its selected quota, base, scope, and ledger. Complete one independent iteration at a time without resetting run state or creating a nested quota. Report exhaustion or blockers rather than substituting another category.
